Discord

Connect DS2000 to your Discord account

  1. 1

    Create your Discord application

    Discord only lets an application control your microphone if you created that application yourself. It is free and only has to be done once.

    Redirect to add under OAuth2 → Redirects: http://localhost/

  2. 2

    Paste its credentials

    The secret is kept in Windows Credential Manager, never in the settings file.

    Saved
  3. 3

    Unlink Discord?

    The Client ID, the secret and the authorisation are deleted. To connect again you will have to paste the credentials again.
